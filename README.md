# PhD — Uzbek Hybrid Information Retrieval

Этот репозиторий является **единым source of truth** для исследовательского контекста PhD по теме:

> **«Гибридный подход к поиску информации на узбекском языке на основе интеграции лексических и семантических методов»**

Основной язык диссертации — русский. Узбекский язык является объектом исследования.

## Назначение репозитория

Здесь хранится не только текст диссертации, но и исследовательская память проекта:

- что уже изучено;
- какие международные и национальные работы найдены;
- что каждая работа действительно доказывает и чего не доказывает;
- как менялся research gap;
- какие гипотезы пока являются рабочими;
- какие решения уже приняты;
- какие вопросы ещё требуют проверки;
- какие источники являются сильными, а какие — только lead для дальнейшего поиска.

Research gap и предполагаемая научная новизна **не считаются замороженными**. Они должны пересматриваться при появлении новых доказательств, после глубокого разбора близких работ и после собственных экспериментов.

## Bootstrap для нового чата

Перед значимой PhD-задачей новый чат должен прочитать:

1. `PROJECT_INSTRUCTIONS.md`
2. `PROJECT_STATE.md`
3. `research/RESEARCH_MAP.md`
4. `research/CURRENT_GAP.md`
5. При работе с конкретной публикацией — её запись в `literature/MASTER_INDEX.md`, а если создан deep dive — соответствующую карточку.

Не следует полагаться только на память предыдущих чатов, если актуальная информация есть в GitHub `main`.

## Структура

- `research/` — состояние исследовательской проблемы, research gap, история его изменений и открытые вопросы.
- `literature/` — мастер-индекс литературы, шаблон глубокого разбора и будущие карточки отдельных работ.
- `decisions/` — принятые и рабочие исследовательские решения с обоснованием.
- `chapters/` — статусы и в дальнейшем Markdown-источники глав.
- `artifacts/` — при необходимости Word/PDF-версии для научного руководителя.
