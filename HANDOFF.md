## 2. Восстановление на новом компьютере (по шагам)

Предполагается та же структура папок: `<КОРЕНЬ>\phd-uzbek-hybrid-retrieval`, где `<КОРЕНЬ>` — аналог `G:\PhD`.

1. Публичный репозиторий уже клонирован. Обновить: `git pull` (ветка `main`).
2. Клонировать приватный репозиторий внутрь проекта:
   ```
   cd <КОРЕНЬ>\phd-uzbek-hybrid-retrieval
   git clone https://github.com/Shoxrux2017/phd-uzbek-hybrid-retrieval-data.git artifacts
   ```
   (`artifacts/` стоит в `.gitignore` публичного репозитория, поэтому они не мешают друг другу.)
3. Распаковать архив с флешки **в `<КОРЕНЬ>`** (не внутрь проекта): пути в архиве повторяют структуру `G:\PhD` (`phd-uzbek-hybrid-retrieval/artifacts/…`, `data/…`, `wikipedia_audit/…` и т.д.), поэтому PDF лягут прямо в нужные папки `artifacts/…` (сначала выполнить шаг 2!). Подробно — в `_TRANSFER/TRANSFER_README.md` внутри архива.
4. Проверить целостность: `python _TRANSFER\TRANSFER_VERIFY.py` (запускать из `<КОРЕНЬ>`) — сверяет SHA-256 всех файлов из архива.
5. Python-окружение `.venv` не переносилось. Пересоздать при необходимости:
   `python -m venv .venv` → `.venv\Scripts\pip install -r code\corpus-profiling\requirements-corpus-profile.txt` (+ `openpyxl` для рабочих книг).
6. В приложении Claude (desktop) подключить папку проекта и папку `<КОРЕНЬ>`; в новом чате написать: «Прочитай HANDOFF.md и продолжим с шага 3 адъюдикации».

## 5. Правила работы (действуют и на новом компьютере)

- Без `git commit/push`, пока первый автор не попросит. Приватные данные — только в приватный репозиторий; PDF — ни в какой.
- Ослепление: файлы в папках `_KEY_do_not_open_before_finishing` не открывать рецензентам до сдачи их рабочих книг; не переписывать решения ИИ в публичные файлы, пока второй рецензент не закончил.
- Всё использование ИИ отмечается честно (AI_FT_01, AI_CC_01 — субагенты Claude; Лутфуллаев — с помощью ChatGPT по его декларации; первый автор проверял сам, без ИИ).
- `research/CURRENT_GAP.md` не менять без согласия первого автора.
- Скачивание файлов и отправка писем — только с явного разрешения; без обхода CAPTCHA/Cloudflare; никаких паролей.
- Одновременно не более 2–3 агентов ИИ.

## 6. Технические заметки

- API OpenAlex/Crossref/Semantic Scholar из оболочки возвращают 403; запросы OpenAlex делались из Chrome (fetch в контексте страницы).
- Оболочка Claude на компьютере (Linux VM) не имеет учётных данных GitHub: коммиты Claude может сделать, а `git push` выполняется из Windows (Git Credential Manager) — см. `PUSH_TO_GITHUB.bat` (если есть) или вручную `git push` в обоих репозиториях.
- Удаление файлов в подключённых папках требует отдельного разрешения в приложении (нужно и для `.git/index.lock`).
- Ранее расширение Claude in Chrome работало на другом компьютере, чем папки проекта: загрузки попадали туда.
