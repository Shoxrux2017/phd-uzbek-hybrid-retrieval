## Current scientific position

Уже установлено:

- BM25 остаётся сильным lexical baseline.
- Learned sparse retrieval показывает, что `sparse != old/non-neural`.
- Dense retrieval решает часть vocabulary mismatch, но не является универсальной заменой lexical retrieval.
- Uzbek morphology и script variation важны для лексического представления.
- Uzbek semantic infrastructure уже существует.
- Uzbek corpus-level semantic retrieval уже оценивается в отдельных работах 2026 года.
- Uzbek hybrid retrieval/RAG уже существует (например, USHRA/O-RAG).
- Поэтому нельзя строить gap на тезисе «для Uzbek hybrid search ничего нет».
- Fixed fusion, RRF и dynamic `alpha(q)` сами по себе давно известны.
